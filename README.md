# Greg's Garden Rescue - Website PoC

Professional garden restoration and maintenance services website.

## 🌿 Features

- **Responsive Design** - Mobile, tablet, and desktop friendly
- **3 Main Pages:**
  - Services (Landing Page)
  - Testimonials
  - Booking Form
- **Contact Form** - Integrated with FormSubmit for email notifications
- **SEO Optimized** - Meta tags, sitemap, structured data included
- **Custom Green Theme** - Natural, garden-inspired design

## 📁 File Structure

```
.
├── index.html              # Services landing page
├── testimonials.html       # Customer testimonials
├── booking.html           # Booking form
├── styles.css             # Main stylesheet
├── script.js              # JavaScript for forms and interactions
├── robots.txt             # SEO - Search engine instructions
├── sitemap.xml            # SEO - Site structure for search engines
├── structured-data.html   # SEO - Schema markup (copy into HTML files)
└── README.md              # This file
```


### GitHub Pages Deployment:
1. Push code to GitHub
2. Settings → Pages → Enable GitHub Pages
3. Select branch (main) and root folder
4. Access at: `https://YOUR-USERNAME.github.io/REPO-NAME/`
5. Add custom domain in settings (optional)



## 🛠️ Technologies Used
