# Git Commands Cheat Sheet for Greg's Garden Rescue

## 🎯 Initial Setup (One-Time Only)

### 1. Navigate to Your Project Folder
```bash
cd /path/to/your/project
```

### 2. Initialize Git (if not already done)
```bash
git init
```

### 3. Connect to Your GitHub Repository
```bash
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
```

### 4. Set Your Git Identity (if not already set)
```bash
git config --global user.name "Your Name"
git config --global user.email "your-email@example.com"
```

---

## 📤 Daily Workflow - Push Changes to GitHub

### The 3-Step Process (Use This Every Time):

```bash
# Step 1: Stage all changes
git add .

# Step 2: Commit with a message
git commit -m "Description of what you changed"

# Step 3: Push to GitHub
git push origin main
```

**Or if your branch is named 'master':**
```bash
git push origin master
```

## 🔍 Helpful Git Commands

### Check Status (What's Changed?):
```bash
git status
```

### See Your Commit History:
```bash
git log --oneline
```

### See What Changed in Files:
```bash
git diff
```

### Undo Changes (Before Commit):
```bash
git checkout -- filename.html
```

### Pull Latest Changes from GitHub:
```bash
git pull origin main
```

### Check Which Remote Repo You're Connected To:
```bash
git remote -v
```

## 🚨 Common Issues & Fixes

### Issue: "fatal: not a git repository"
**Fix:**
```bash
git init
```

### Issue: "remote origin already exists"
**Fix:**
```bash
git remote remove origin
git remote add origin https://github.com/YOUR-USERNAME/YOUR-REPO-NAME.git
```

### Issue: "refusing to merge unrelated histories"
**Fix:**
```bash
git pull origin main --allow-unrelated-histories
```

### Issue: "src refspec main does not match any"
**Fix:** Your branch might be called 'master' instead:
```bash
git push origin master
```

Or rename your branch to main:
```bash
git branch -M main
git push -u origin main
```

### Issue: Need to undo last commit (but keep changes)
**Fix:**
```bash
git reset --soft HEAD~1
```

## 🎨 VS Code Git Integration

### Instead of Terminal Commands, You Can:

1. **Stage Changes:** Click the + icon next to files in Source Control panel
2. **Commit:** Type message in text box, click ✓ checkmark
3. **Push:** Click the "..." menu → Push
4. **Pull:** Click the "..." menu → Pull

**Pro Tip:** Use `Ctrl+Shift+G` to open Source Control panel

## 🌐 Enable GitHub Pages (One-Time Setup)

1. Go to your repository on GitHub.com
2. Click **Settings** tab
3. Scroll to **Pages** section (left sidebar)
4. Under "Source", select **main** branch and **/ (root)** folder
5. Click **Save**
6. Wait 1-2 minutes
7. Your site will be live at: `https://YOUR-USERNAME.github.io/REPO-NAME/`

### Add Custom Domain (Optional):
1. In Pages settings, add your domain
2. Update DNS settings at your domain registrar
3. Enable "Enforce HTTPS"

**💡 Pro Tip:** Commit often! Small, frequent commits are better than large infrequent ones. Aim to commit every time you complete a logical chunk of work (fix a bug, add a feature, update content, etc.)

**🔒 Security Note:** Never commit sensitive data like API keys, passwords, or real customer data. Use environment variables or .env files (already in .gitignore).
